# Piya Dutta - Professional Portfolio & Resume

Official portfolio website of **Piya Dutta**, Diploma in Civil Engineering & Computer Science student with 2 years of Computer Teaching experience.

## 🚀 Features

- **Modern Glassmorphic UI**: High-end responsive portfolio with dark/light mode toggle.
- **Instant Base64 PDF CV Download**: One-click offline CV download system powered by automated scripts.
- **Responsive Layout**: Designed for seamless viewing across mobile, tablet, and desktop screens.

## 🛠️ Project Structure

```
d:/cv/
├── assets/                  # Public image and PDF assets
├── public/assets/           # Build asset files
├── src/                     # Source JavaScript and CSS modules
│   ├── cv-data.js           # Base64 PDF data module
│   ├── main.js              # Application logic & interactive state
│   └── style.css            # Complete design system and styling
├── scripts/                 # Build & automated PDF generation scripts
├── index.html               # Main website entry point
├── package.json             # Project dependencies and npm scripts
└── vite.config.js           # Vite development and build configuration
```

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 📤 Pushing to GitHub

To upload this repository to GitHub, run the following commands in your terminal:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.name.git
git branch -M main
git push -u origin main
```
